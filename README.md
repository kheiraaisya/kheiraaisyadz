# Kheidz Portfolio

Selamat datang di repositori website portofolio pribadi **Kheira Aisya Dzikri**! Website ini dibangun untuk menampilkan profil, keterampilan, serta berbagai prestasi yang telah diraih.

## 🚀 Tentang Website

Website ini merupakan portofolio interaktif yang dibangun menggunakan teknologi dasar web development dengan framework modern untuk memastikan tampilan yang responsif, menarik, dan profesional.

**Fitur Utama & Bagian Website:**
- **Beranda (`#home`)**: Perkenalan singkat mengenai Kheira Aisya Dzikri sebagai Mahasiswa Informatika di Universitas Negeri Semarang.
- **Keterampilan (Marquee)**: Animasi berjalan (marquee) yang menampilkan berbagai keahlian seperti *Basic HTML 5, Basic CSS, Basic PYTHON, Scientific Writing, Microsoft Office, Research & Analysis,* dan *Bootstrap 5*.
- **Tentang Saya (`#about`)**: Deskripsi singkat mengenai latar belakang dan penjelasan dari beberapa keahlian utama (HTML, CSS, Python).
- **Prestasi (`#achievement`)**: Daftar pencapaian dan penghargaan tingkat nasional di bidang riset (kompetisi esai dan karya tulis ilmiah), lengkap dengan gambar dokumentasi dan tautan ke halaman detail sertifikat.
- **Kontak (`#contact`)**: Formulir kontak fungsional yang terintegrasi dengan Web3Forms, memungkinkan pengunjung untuk langsung mengirim pesan.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur dasar dan semantik halaman web.
- **CSS3 & Bootstrap 5**: Styling halaman, layout yang responsif, dan komponen UI siap pakai.
- **AOS (Animate On Scroll)**: Library untuk memberikan efek animasi visual yang mulus saat halaman digulir.
- **Bootstrap Icons**: Ikon-ikon minimalis yang digunakan pada bagian tentang dan footer.
- **Google Fonts**: Menggunakan font *Poppins* dan *Montserrat* untuk memberikan gaya tipografi yang modern.

## 📂 Struktur File Utama

- `index.html`: Halaman utama website portofolio.
- `styleportof.css`: File CSS kustom untuk styling tambahan di luar Bootstrap.
- `detail1.html` - `detail5.html`: Halaman yang menampilkan detail atau sertifikat untuk masing-masing prestasi.
- `photo/`: Direktori yang berisi semua aset gambar (foto profil, sertifikat, dll).
